Linear Approximation

Read Section 3.9

Introduction

Tangent lines have come up several times in relation to the idea of the derivative. In Unit 2, we used them to understand the derivative as the slope of a curve at a point, and in Unit 3 we developed rules that make finding them quick. But what are tangent lines actually good for?

NoteRecall: The Tangent Line

The line tangent to the graph of \(f(x)\) at \(x=a\) passes through the point \(\big(a,f(a)\big)\) and has slope \(f'(a)\). Its equation is \[ y = f(a) + f'(a)(x-a). \]

When you zoom in far enough on the graph of a function at a point where it is differentiable, the graph looks more and more like a straight line, and that line is the tangent line. This means that near \(x=a\), we can use the tangent line in place of the function itself: \[ f(x) \approx f(a) + f'(a)(x-a) \qquad \text{for } x \text{ near } a. \] This is called the linear approximation (or tangent line approximation) of \(f(x)\) near \(x=a\). Linear functions are about the simplest functions there are to evaluate and solve, so replacing a complicated function with a line, even just locally, can be very useful.

In this section, we will see that the tangent line is not just a good linear approximation for \(f(x)\) near \(x=a\). In a precise sense, it is the best local linear approximation.

Problem 1 - Estimating a Square Root

In this problem, we will estimate \(\sqrt{1.2}\) without using a calculator or other computational tool. Let \(f(x)=\sqrt{x}\).

  1. Find \(L_a(x)\), the line tangent to \(f(x)=\sqrt{x}\) at \(x=a\), where \(a\) is selected so that
    1. \(a\) is close to \(1.2\), and
    2. \(a\) is a “nice” number, so that \(f(a)\) and \(f'(a)\) are easy to calculate.
  2. Use your tangent line to estimate the value of \(\sqrt{1.2}\).
  3. Now, use Desmos to graph \(f(x)\) and the tangent line you found. Determine the error in your approximation. (We calculate the error as \(E(1.2) = \text{Actual Value} - \text{Estimated Value}\).)
  4. In what sense is the tangent line you found, \(L_a(x)\), the best local linear approximation for \(f(x)\) near \(x=a\)? Graph other lines through the point \(\big(a,f(a)\big)\). What makes the tangent line the best approximation?
  5. Use a table of values to estimate \[ \lim_{x\to a}\frac{E(x)}{x-a} \qquad\text{and}\qquad \lim_{x\to a}\frac{E(x)}{(x-a)^2}. \] In class, we will talk about how the first limit characterizes what we mean by “best.” The second limit gives us a sense of how large the error in our approximation will be for \(x\)-values close to \(a\): it is roughly proportional to \((x-a)^2\).

Problem 5 - Solving Equations with Tangent Lines

Approximating nonlinear behavior with linear behavior can be very useful in computational algorithms. One example of this is using linear approximation to approximate solutions to equations involving nonlinear functions.

For example, it is easy to solve the equation \(p(x)=0\) when \(p(x)\) is a linear function, and there is a relatively simple formula (the quadratic formula) that tells us how to find the solutions when \(p(x)\) is a quadratic function. There are much longer and more complicated formulas for finding the solutions when \(p(x)\) is a third or fourth degree polynomial. For fifth or higher degree polynomials, there is no general formula that tells us how to find the solutions!

So, in general, if we want to solve an equation like \(p(x)=0\), where \[ p(x)=x^5+x+1, \] often the best we can do is estimate the solutions numerically. Below, we will see how linear approximation lets us get accurate approximations in just a few steps.

  1. First, compute \(p(-1)\) and \(p(0)\). Why do we know there is a solution to \(p(x)=0\) between \(x=-1\) and \(x=0\)?
  2. Let’s start with \(x_0 = -1\) as our initial guess for the solution to \(p(x)=0\).
    • Find \(L_0(x)\), the line tangent to \(p(x)\) at \(x=-1\).
    • Solve \(L_0(x)=0\). Call the solution to this equation \(x_1\).
    • Graph \(L_0(x)\) and \(p(x)\). Is \(x_1\) a better approximation for the solution to \(p(x)=0\) than \(x_0=-1\)?
  3. Now repeat what you did in part (b), starting from \(x_1\):
    • Find \(L_1(x)\), the line tangent to \(p(x)\) at \(x=x_1\).
    • Solve \(L_1(x)=0\). Call the solution to this equation \(x_2\).
    • Graph \(p(x)\), \(L_0(x)\), and \(L_1(x)\). Is \(x_2\) a better approximation for the solution to \(p(x)=0\) than \(x_1\) and \(x_0\)?
  4. What will happen if we continue to repeat this process?

The procedure in Problem 5 is called Newton’s Method. Versions of it are used by calculators and computer software to solve equations that can’t be solved exactly by hand.

Why the Tangent Line Is the Best

TipThe Tangent Line Is the Only Line with \(\lim_{x\to a}\frac{E(x)}{x-a}=0\)

Every line that passes through the point \(\big(a,f(a)\big)\) has an equation of the form \(y = f(a) + m(x-a)\) for some slope \(m\). All of these lines give the exact value of \(f\) at \(x=a\), so to decide which is best, we have to look at how the error behaves for \(x\) near \(a\).

Justification: The error in using the line with slope \(m\) to approximate \(f(x)\) is \[ E(x) = f(x) - \big(f(a) + m(x-a)\big). \] Dividing by \(x-a\) gives \[ \frac{E(x)}{x-a} = \frac{f(x)-f(a)}{x-a} - m. \] The first term is a difference quotient, so as \(x\to a\) it approaches \(f'(a)\). This means \[ \lim_{x\to a}\frac{E(x)}{x-a} = f'(a) - m. \] This limit equals \(0\) if and only if \(m=f'(a)\), that is, exactly when the line is the tangent line.

For any other line, the error \(E(x)\) shrinks to \(0\) at about the same rate as \(x-a\) does. For the tangent line, the error shrinks to \(0\) faster than \(x-a\). That is the sense in which the tangent line is the best local linear approximation. \(\qquad \blacksquare\)
