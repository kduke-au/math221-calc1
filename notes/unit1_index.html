Limits & Continuity - Introduction

Creating the proper tools that allow us to measure rate and accumulation require us to grapple with infinities and infinitesimals. Here are some examples that illustrate the logical hurdle these ideas pose:

Discussion Problem: Infinities and Infinitesimals

Discuss and try to resolve one or more of the following questions with your group.

  1. Consider a hotel with infinitely many rooms. Currently each room is occupied. A new guest arrives at the front desk and requests a room. Can they be accommodated? If so, how?

  2. Consider the value \(0.999\ldots\) where there is a 9 in all decimal places. This value is the result of an infinite process:

    • Start with 0.9
    • Add 9 hundredths to get 0.99
    • Add 9 thousandths to get 0.999
    • And so on …

    At each step of this process, the value \(0.99\ldots 9\) is getting closer to, but always less than 1. So, \(0.999\ldots\) must be infinitesimally close to, but less than 1. Do you agree?

  3. Someone is turning a lamp on and off over the course of 1 minute

    • The lamp starts on.
    • It is turned off after 1/2 of a minute.
    • It is turned back on at 3/4 of a minute.
    • It is turned off again at 7/8 of a minute.
    • Then turned back on again at 15/16 of a minute.
    • And so on…

    Does the lamp end up off or on after 1 minute?

  4. Construct an infinite staircase as follows.

  • Start with one step that is 1m long and rises 1m. The total length is 2m.
  • Now add another step. So now, each step is 0.5m long and rises 0.5m. The total length of the staircase is still 2m.
  • Continue in this fashion as shown in the graph below. At each iteration, the staircase as \(n\) steps, each one runs \(\frac{1}{n}\) meters and rises \(\frac{1}{n}\) meters and so the total length of the staircase is always 2m.
viewof n = Inputs.range([1, 100], {value: 4, step: 1, label: "Number of steps (n)"})
stairPoints = {
  const pts = [{x: 0, y: 0}];
  for (let i = 0; i < n; i++) {
    const y0 = i / n;
    const x1 = (i + 1) / n;
    const y1 = (i + 1) / n;
    pts.push({x: x1, y: y0});
    pts.push({x: x1, y: y1});
  }
  return pts;
}
diagPoints = [{x: 0, y: 0}, {x: 1, y: 1}]
stairLength = {
  let total = 0;
  for (let i = 1; i < stairPoints.length; i++) {
    const dx = stairPoints[i].x - stairPoints[i - 1].x;
    const dy = stairPoints[i].y - stairPoints[i - 1].y;
    total += Math.hypot(dx, dy);
  }
  return total;
}
diagLength = Math.hypot(1, 1)

The process results in a staircase with infinitely many steps that has a total length of 2m. Therefore the length of the diagonal shown in the diagram must also be 2m. Do you agree?

Big Idea

Paradoxes or controversies are not allowed in mathematics. They are the result of a lack of clarity. Either the question has not been posed clearly, terms have not been clearly defined, or assumptions have not been clearly stated.

The key idea that we will need before we can proceed to our main goals is the limit. In this unit, we will define limits, develop our conceptual understanding of them, and determine some rules and algebraic procedures that can be used to compute some types of limits precisely.
