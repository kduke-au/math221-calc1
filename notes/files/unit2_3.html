The Derivative Function

Read Section 2.3

Introduction

Last time, we defined the derivative of a function \(f(x)\) at a single point \(x=a\). The value \(f'(a)\) measures the instantaneous rate of change of \(f(x)\) at \(x=a\), which we can see graphically as the slope of the line tangent to the graph of \(f(x)\) at that point.

In our first discussion problem, we estimated \(f'(a)\) for the function \(f(x)=0.5x(x-3)(x-5)\) at the points \(x=0, 1, 2, 3, 4,\) and \(5\). Each of these estimates gave us one number describing the slope of \(f(x)\) at one point. But there is nothing special about these six points: we could estimate the slope of \(f(x)\) at any point \(x=a\) in the same way.

If we can find \(f'(a)\) for every value of \(a\), then we have a rule that takes each input \(x\) and returns the slope of \(f(x)\) at that point. In other words, \(f'\) is itself a function!

We call this new function the derivative function, or simply the derivative, of \(f(x)\). Its formula comes directly from our definition of the derivative at a point: we just replace the specific point \(a\) with a variable input \(x\).

Definition 1 (The Derivative Function) The derivative of \(f(x)\) is the function \[f'(x)=\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}.\] The domain of \(f'(x)\) consists of all values of \(x\) for which this limit exists.
