Using the First and Second Derivatives

Read Section 4.1

Introduction

In this section, we put together just about everything we have discussed so far this semester! The goal is to determine as many important features of the behavior of a function \(f(x)\) as we can, working without any aid from computational tools.

Important features include:

  • domain and range,
  • continuity and differentiability,
  • intervals where \(f(x)\) is increasing or decreasing,
  • concavity,
  • points where these behaviors change, like relative extrema and inflection points, and
  • end behavior: what happens to \(f(x)\) as \(x\) approaches the boundaries of the domain of \(f(x)\)?

Ultimately, we want to learn as much about \(f(x)\) as we can from its formula and the formulas of its derivatives, so that we can sketch a complete graph of \(f(x)\).

NoteRecall: What the Derivatives Tell Us
  • If \(f'(x)>0\) on an interval, then \(f(x)\) is increasing on that interval. If \(f'(x)<0\) on an interval, then \(f(x)\) is decreasing on that interval.
  • If \(f''(x)>0\) on an interval, then \(f(x)\) is concave up on that interval. If \(f''(x)<0\) on an interval, then \(f(x)\) is concave down on that interval.
NoteDefinitions: Points Where Behavior Changes
  • A critical point of \(f(x)\) is a point \(x=p\) in the domain of \(f(x)\) where \(f'(p)=0\) or \(f'(p)\) is undefined.
  • \(f(x)\) has a local (relative) maximum at \(x=p\) if \(f(p)\geq f(x)\) for all \(x\) near \(p\), and a local (relative) minimum at \(x=p\) if \(f(p)\leq f(x)\) for all \(x\) near \(p\). Together, these are called local (relative) extrema.
  • An inflection point of \(f(x)\) is a point \(x=p\) in the domain of \(f(x)\) where the concavity of \(f(x)\) changes.

Discussion Problems

Problem 1 - A Familiar Shape

Let \(f(x)=e^{-x^2}\).

  1. Find the domain of \(f(x)\), and determine where \(f(x)\) is continuous and where it is differentiable.
  2. Find \(f'(x)\) and \(f''(x)\).
  3. Determine where \(f(x)\) is increasing and where it is decreasing.
  4. Determine where \(f(x)\) is concave up and where it is concave down.
  5. Does \(f(x)\) have any relative extrema? Any inflection points? If so, where?
  6. Determine the end behavior of \(f(x)\). That is, find \(\displaystyle\lim_{x\to\infty} f(x)\) and \(\displaystyle\lim_{x\to-\infty} f(x)\).
  7. Sketch a complete graph of \(f(x)\) that illustrates its important features. Have you seen this graph before? Where?

Summary: Local Extrema and Inflection Points

TipUsing \(f'(x)\) and \(f''(x)\) to Classify Points (click to expand)

As you worked through the problems, you may have noticed that every local extremum occurred at a critical point of \(f(x)\), and that we can use \(f'(x)\) or \(f''(x)\) to try to determine whether a critical point is a local extremum. Here is a summary of those observations that is useful to remember.

Using the first derivative. If \(x=a\) is a critical point of \(f(x)\), then \(f(x)\) has a local extremum at \(x=a\) if \(f'(x)\) changes sign at \(x=a\):

  • If \(f'(x)\) changes from negative to positive at \(x=a\), then \(f(x)\) has a local minimum at \(x=a\).
  • If \(f'(x)\) changes from positive to negative at \(x=a\), then \(f(x)\) has a local maximum at \(x=a\).

Using the second derivative. We can also determine whether \(f(x)\) has a local extremum at a critical point if we know the concavity of \(f(x)\) near the critical point. If \(x=a\) is a critical point of \(f(x)\) and

  • \(f''(a)\) is positive, then \(f(x)\) is concave up near \(x=a\), so \(f(x)\) must have a local minimum at \(x=a\).
  • \(f''(a)\) is negative, then \(f(x)\) is concave down near \(x=a\), so \(f(x)\) must have a local maximum at \(x=a\).

Inflection points. You may have also noticed that just because \(x=a\) is a critical point of \(f'(x)\) (that is, \(f''(a)\) is \(0\) or undefined), it is not guaranteed that \(x=a\) is an inflection point of \(f(x)\). You have to check whether the concavity actually changes there. So,

\[ x=a \text{ is an inflection point of } f(x) \text{ if and only if } f''(x) \text{ changes sign at } x=a. \]
