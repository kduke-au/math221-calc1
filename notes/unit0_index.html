What is Calculus?

Calculus provides us with a framework in which we can measure the effects of change and use this to better understand relationships between variables.

There are two main problems we will consider this semester:

  1. Rates. Given a relationship between variables, can we measure how sensitive one variable is to small changes in others?
  2. Accumulation. If we understand a variables sensitivity to small changes, can we measure its total change in response to a much larger change in the other variables?

Discussion Problem: The Vessel

\[ x = r(y) = \sin\!\left(\frac{\pi y}{4}\right) + 1.5, \qquad 0 \le y \le 8, \]

function r(y) {
  return Math.sin((Math.PI * y) / 4) + 1.5;
}

function crossSectionArea(y) {
  const radius = r(y);
  return Math.PI * radius * radius;
}
yMax = 8
numSteps = 4000
stepSize = yMax / numSteps

yGrid = d3.range(0, numSteps + 1).map((i) => i * stepSize)
areaGrid = yGrid.map(crossSectionArea)

volumeGrid = {
  const cumulative = [0];
  for (let i = 1; i <= numSteps; i++) {
    const trapezoid = ((areaGrid[i - 1] + areaGrid[i]) / 2) * stepSize;
    cumulative.push(cumulative[i - 1] + trapezoid);
  }
  return cumulative;
}

totalVolume = volumeGrid[numSteps]

// Choose the fill rate so that it takes a specified amount of time to fill.
fillRate = totalVolume / 20
totalTime = 20
function depthAtTime(t) {
  const targetVolume = fillRate * t;
  const i = d3.bisectLeft(volumeGrid, targetVolume);
  if (i <= 0) return 0;
  if (i >= volumeGrid.length) return yMax;
  const v0 = volumeGrid[i - 1], v1 = volumeGrid[i];
  const y0 = yGrid[i - 1], y1 = yGrid[i];
  const frac = v1 === v0 ? 0 : (targetVolume - v0) / (v1 - v0);
  return y0 + frac * (y1 - y0);
}

// dy/dt = (dV/dt) / A(y) = fillRate / crossSectionArea(y(t)).
function rateAtTime(t) {
  const y = depthAtTime(t);
  return fillRate / crossSectionArea(y);
}

Wrap-Up

The first graph you created showing depth vs. time is an example of an accumulation problem; the depth increased as the water flowed in and our goal was to figure out the total depth reached at each moment as the water accumulated. We will see later this semester (Unit 5) that the integral is the right mathematical tool for accumulation problems.

The second graph you created is an example of a rate problem; the goal was to understand how quickly the depth of the water was increasing at each moment. We will see in Unit 2 that the derivative is the right mathematical tool for rate problems.

Our goal this semester is to carefully define each of these tools, understand how they work, deduce some computational rules, and see how they can be applied to problems in a wide array of fields. Ultimately, our work will reveal that these two problems are closely connected, and that relationship will be explained in the Fundamental Theorem of Calculus.
