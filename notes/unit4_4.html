Global Extrema

Read Section 4.2

Introduction

In the previous section, we used the first and second derivatives to find local maximums and minimums: points where a function is larger or smaller than at all nearby points. In many applications, though, we want to know something stronger. What is the largest or smallest value a function takes on over an entire interval?

NoteDefinitions: Global Extrema

Let \(f(x)\) be a function defined on an interval \(I\), and let \(p\) be a point in \(I\).

  • \(f(x)\) has a global (absolute) maximum on \(I\) at \(x=p\) if \(f(p)\geq f(x)\) for all \(x\) in \(I\). The value \(f(p)\) is called the global maximum value of \(f(x)\) on \(I\).
  • \(f(x)\) has a global (absolute) minimum on \(I\) at \(x=p\) if \(f(p)\leq f(x)\) for all \(x\) in \(I\). The value \(f(p)\) is called the global minimum value of \(f(x)\) on \(I\).

Together, these are called the global (absolute) extrema of \(f(x)\) on \(I\).

Notice that whether a function has global extrema depends on the interval \(I\) as well as on the function. Global extrema also don’t always have to exist!

Discussion Problems

Problem 0 - Do Global Extrema Always Exist?

Come up with examples of a function \(f(x)\) and an interval \(I\) where

  1. \(f(x)\) has neither a global maximum nor a global minimum on \(I\).
  2. \(f(x)\) has only one of a global maximum or a global minimum on \(I\).
  3. \(f(x)\) has both a global maximum and a global minimum on \(I\).
  4. \(f(x)\) is bounded on \(I\) (its values never go above or below some fixed numbers), but \(f(x)\) has neither a global maximum nor a global minimum on \(I\).

A sketch of the graph of \(f(x)\) over \(I\) is enough for each example, though see if you can also find formulas. Try using different kinds of intervals: closed intervals like \([a,b]\), open intervals like \((a,b)\), and intervals that go off to infinity. You might also try functions that are not continuous.

What do the examples where global extrema don’t exist have in common? What would you need to rule out to guarantee that both global extrema exist?

NoteTheorem: The Extreme Value Theorem

If \(f(x)\) is continuous on a closed interval \([a,b]\), then \(f(x)\) has both a global maximum and a global minimum on \([a,b]\).

Problem 1 - A Polynomial

Let \(f(x)=\dfrac{3}{2}x^4+2x^3-6x^2+4\). Find the exact location and value of the global maximum and the global minimum (if they exist) of \(f(x)\) on each of the following intervals:

  1. \([0,4]\)
  2. \((-\infty, \infty)\)

Problem 2 - Open and Infinite Intervals

Find the exact location and value of the global maximum and the global minimum (if they exist) of the function \(f(x)=xe^{-x^4}\) on each of the following intervals:

  1. \([-1, 0.5]\)
  2. \((0,\infty)\)

Problem 3 - A Discontinuous Function

Find the global maximum and the global minimum (if they exist) of the function \(f(x)=x+\dfrac{4}{x}\) on each of the following intervals:

  1. \([-4, 4]\)
  2. \([1,3]\)

Problem 4 - The Peak of an Epidemic

As an epidemic spreads through a population, the number of infected people, \(I\), can be expressed as a function of the number of susceptible people, \(S\), by \[ I=k\ln\left(\frac{S}{S_0}\right)-S+S_0+I_0, \] where \(k\), \(S_0\), and \(I_0\) are positive constants. (This relationship comes from the SIR model for infectious diseases.)

  1. Find the maximum number of infected people.
  2. The constant \(k\) is a characteristic of the particular disease. The constants \(S_0\) and \(I_0\) are the initial values of \(S\) and \(I\). Which of the following affects the maximum possible value of \(I\)? Make sure you can explain your answer.
    • The particular disease, but not how it starts.
    • How the disease starts, but not the particular disease.
    • Both the particular disease and how it starts.

Strategy: Finding Global Extrema

TipA General Strategy for Finding Global Extrema (click to expand)

Step 1: Is \(f(x)\) continuous on a closed interval \(I\)?

  • If yes: By the Extreme Value Theorem, both global extrema must exist, and they occur either at critical points of \(f(x)\) in \(I\) or at the endpoints of \(I\). Find all of the critical points in \(I\), and evaluate \(f(x)\) at each of them and at the endpoints. The largest of these values is the global maximum, and the smallest is the global minimum.

  • If no: The global extrema may or may not exist, so we need to look more carefully. Go on to Step 2.

Step 2: Check the behavior at the “edges.” Determine the end behavior of \(f(x)\) on \(I\) (what happens as \(x\) approaches each endpoint of \(I\), or \(\pm\infty\)), as well as the behavior near any points in \(I\) where \(f(x)\) is not continuous. This behavior may tell you that one or both of the global extrema do not exist. For example, if \(f(x)\to\infty\) anywhere, there is no global maximum.

Step 3: Look for the extrema that might exist. If \(f(x)\) is bounded from above or from below, a global maximum or global minimum may exist. If it does, it must again occur either at an endpoint of \(I\) or at a critical point of \(f(x)\) in \(I\).

Step 4: Put together a complete argument. Build a good understanding of \(f(x)\) using the ideas from the previous section: find all of the critical points, determine whether they are local extrema, and use where \(f(x)\) is increasing and decreasing, together with its behavior from Step 2, to give a complete argument for whether or not the global extrema exist and where they occur.
